# openrajska/.github

Organization-wide files for [OpenRajska](https://github.com/openrajska).

- `profile/README.md` is the page shown at [github.com/openrajska](https://github.com/openrajska).
- `brand/` holds the logo: `openrajska-mark.svg` (the source) and PNG exports from 16 to 1024 px.

Community health files placed here, such as `SECURITY.md` or issue templates, apply to every OpenRajska repository that does not have its own.
